# Kind Recall demo sandbox

- URL: <https://kind-recall.sociobot.in/demo/>
- Entry: choose **Try it with sample data** on the first screen.
- Sample: six due vocabulary entries with personal contexts: sobremesa, meraki, dépaysement, saudade, komorebi, and passeggiata.
- Storage: IndexedDB database `kind-recall-demo`. The normal product uses the separate `kind-recall` database.
- Reset: **Reset demo** clears the demo database and restores the six original entries.
- Leave: **Start for real** clears demo data and opens the normal product. It never copies sample activity into the real sheet.
- Offline: visit the demo once online, then it can be reloaded and used offline through the same service worker as the product.
